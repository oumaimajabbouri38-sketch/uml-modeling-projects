Ce dépôt contient mes travaux pratiques (TPs), diagrammes d'analyse et de conception logicielle développés pour le module **UML & Modélisation** durant le semestre S3.

---

## 📂 Structure du Dépôt

| Dossier / Diagramme | Description | Type de Diagramme |
| :--- | :--- | :--- |
| 🎯 `TP1-Use-Cases` | Modélisation des besoins utilisateurs et cas d'utilisation. | Diagramme de Cas d'Utilisation |
| 🏢 `TP2-Class-Diagrams` | Conception de la structure statique, classes, attributs et relations. | Diagramme de Classes |
| 🔄 `TP3-Sequence-Diagrams` | Modélisation des interactions dynamiques et échanges de messages. | Diagramme de Séquence |
| 📊 `TP4-State-Activity` | Analyse des états du système et flux d'activités. | Diagramme d'États / Activités |
| 🚀 `Mini-Projet-Conception` | Dossier complet d'analyse et de conception UML d'un système. | Projet Global |

---

## 🧠 Concepts & Diagrammes Couverts

- **Diagrammes Statiques :** Diagramme de Classes, Diagramme d'Objets, Diagramme de Paquetages.
- **Diagrammes Dynamiques :** Diagramme de Cas d'Utilisation (Use Cases), Diagramme de Séquence, Diagramme d'Activités, Diagramme d'États-Transitions.
- **Concepts Orientés Objet :** Encapsulation, Héritage, Polymorphisme, Association, Agrégation et Composition.

---

## 🛠️ Outils de Modélisation

- **Logiciels :** StarUML, PlantUML, Draw.io / Diagrams.net
- **Langage de Description :** UML 2.5 Standard
